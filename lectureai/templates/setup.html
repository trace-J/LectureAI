LectureAI setup
All of your lectures, in one place
Control panel →

Everything here is saved on this Mac only, in ~/.lectureai. Come back any time to change one thing; the rest stays as it is.

You're all set. Open the control panel to record your first lecture.

1 API keys

Two services do the work, each billed to your own account. OpenAI transcribes the audio and Anthropic writes the summary. Create a key at each link and paste it here.

2 Microphone

Which microphone to record lectures from. The built-in one is usually right.

3 Class schedule

One line for every time a class meets. Recordings are filed under the class that starts nearest the time you began recording.

DayStarts atCourse code
Course codes become Drive folder names, like ACCT-4321.
Advanced: matching window minutes. How far from a class's start time a recording can begin and still count as that class. Keep it well under the gap between back-to-back classes: with a 12:00 and a 14:00 on the same day, anything near 60 lets the wrong class win.

4 Notion (optional)

Create an internal integration at notion.so/my-integrations and copy its secret. Then open your to-do database in Notion, choose Connections under the … menu, and add the integration. Without that step Notion answers every request with 404.

Paste the whole address from your browser while the database is open.

5 Google Drive

Summaries are filed as Google Docs in a "Lecture Notes" folder in your own Drive. Connecting opens Google in a new tab; sign in and allow access. The app can only see files it created itself.
